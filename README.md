# 🎯 Current Projects

## 🔴 Redline — High Performance HTTP Framework

A lightweight HTTP framework built directly on Node's `http` module.

### Features

- 🚀 Optimized routing engine
- ⚙️ Worker-based concurrency
- 📦 Static file caching
- 🧩 Middleware support
- 🎥 HTTP Range requests (video streaming)
- 🔒 Secure routing & path validation

**Performance**

> Benchmarked at **300K+ requests/sec** in local load tests.
